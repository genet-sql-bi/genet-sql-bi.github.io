Olist Dataset · PostgreSQL to Power BI

Brazilian E-Commerce Analytics

An end-to-end analysis of the Olist Brazilian E-Commerce dataset (~100K orders, 2016–2018). The data lives in PostgreSQL, is analyzed in SQL and Python, then modeled and cleaned in Power Query and presented in a four-page Power BI dashboard covering Sales, Customers, Logistics and Reviews.

Late deliveries cut the average review score from 4.29 to 2.57. Logistics performance directly drives customer satisfaction.

DAX highlights

03 / TECHNIQUE

Three measures that do the analytical work behind the dashboard:

Calculated column

Delivery status

Classifies each order as On Time, Late or Not Delivered by comparing delivered vs estimated dates. This powers the headline review-score comparison.

Measure

Dynamic highlight color

Uses MAXX over ALLSELECTED to color the top category green and the rest gray, updating with every slicer.

Measure

Minimum-sample rating

Excludes categories with fewer than 100 reviews before ranking, so small categories can't top the list by chance.

Design choices

04 / VALIDATION
  • Consistent color logic: green for the top item, red for problems, gray for everything else
  • Honest axes: the delivery trend starts at 0, so changes aren't exaggerated
  • Clear revenue definitions: total revenue uses payment value (incl. freight); category revenue uses item price
  • Brazilian currency (R$) throughout, since all values are in BRL
